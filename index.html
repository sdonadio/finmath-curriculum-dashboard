What a course page is for

A course page is a study guide, not a syllabus. Read a week before the lecture to know what is coming; read it after to check you can answer the questions without notes. Every code block on it was actually executed and its printed output stored, so nothing on the page claims a result the code does not produce. Each page prints cleanly if you would rather work on paper.

Privacy

Weeks you have opened and questions you have answered are stored in this browser only (localStorage). Nothing is sent anywhere, no account is involved, and no instructor can see it. Clearing your browser data clears your progress.
